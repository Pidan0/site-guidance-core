# 展示与询盘站执行

适用：核心目标能用信息页面和联系入口完成。已有商城或预约系统也可采用展示站加明确外链，前提是在brief中确认外部承接。

## 动作

1. 确定目标受众、首要行动、语言、页面与维护方。
2. 取得品牌、介绍、产品或服务、联系方式和可使用素材。未提供的价格、资质、销量不能补写。
3. 参考site示例填写每种语言内容，产品／服务用稳定id对应。此版本只生成文本结构；图片与其他媒体需要按实际项目增加资源模块和授权核对。
4. init、build，检查本地结果和GUIDANCE。用户或设计执行者在目标设备检查实际可读性。
5. 通过update改资料，再build。旧版本保留；发现手改站点时先保留和核对修改，不能覆盖。
6. 试走联系入口，记录哪一种路径已经验证。邮件客户端能打开不等于邮件已送达。
7. 按publishing准备公开包和交接。

## 交付与验收

网站文件、内容源、当前版本、检查结果和维护说明齐全。真实表单为单独接入项；外链购票或购买只证明入口存在，订单与收入需要外部系统回传证据。
